# Route Optimizer (Full Stack)

## Overview
Route Optimizer is a full-stack web application inspired by Google Maps, designed to compute the most efficient route across multiple destinations using official Google APIs.

## Architecture
- Frontend: Vite + React
- Backend: Python (UV) on Google Cloud Functions
- Services: Firebase Authentication, Google Maps APIs

## Features
- Add multiple destinations
- Compute fastest route
- Interactive map visualization
- Firebase authentication

## Setup
1. Clone repository
2. Configure environment variables
3. Install dependencies (frontend/backend)
4. Run services

## APIs Used
- Google Maps JavaScript API
- Distance Matrix API
- Firebase Auth
