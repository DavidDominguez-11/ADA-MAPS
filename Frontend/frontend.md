# Frontend - Route Optimizer

## Overview
React (Vite) frontend providing a Google Maps-like interface for route optimization.

## Features
- Interactive map
- Add/remove destinations
- Display optimized route
- Firebase authentication

## Tech Stack
- React + Vite
- Google Maps JavaScript API
- Firebase Auth

## Setup
1. npm install
2. Configure .env
3. npm run dev

## Build
npm run build
